홈 화면 위젯 (선택)

목록이 홈 화면에 늘 떠 있게 하고 싶을 때만. 아이폰은 무료 앱 Scriptable 위에서 위젯을 띄워요.

  1. Scriptable 설치 (무료)App Store 열기
  2. 위젯 파일 받기 → 「다운로드」 → 받은 파일을 눌러 Scriptable로 열기 → 추가위젯 파일 받기
  3. 위젯 연결 — 이 홈 화면 앱의 연결을 그대로 넘겨요 (메일 코드 다시 안 받아도 돼요)
  4. 홈 화면에 놓기 — 빈 곳 길게 누르기 → 왼쪽 위 ＋ → Scriptable → 중간 크기 추가 → 위젯을 길게 눌러 위젯 편집 → Script: 본부 타임라인
위젯의 ＋를 누르면 바로 할 일을 적을 수 있고, 나머지를 누르면 메뉴가 떠요. 잠금 화면 위젯도 같은 방법으로 놓을 수 있어요.
